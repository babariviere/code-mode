# Architecture

`packages/core` is host-independent. Each invocation type-checks and transpiles TypeScript, then runs the emitted program in a fresh QuickJS context. The context receives only JSON payloads, bounded state, `print`, and proxies for tools explicitly registered by the trusted host.

Hosts register capability-oriented IDs (`web.search`, `sandbox.exec`, `workspace.read`) before execution. `tools.search` is a built-in discovery operation. Registration validates IDs and capabilities, and policies filter both generated declarations and runtime dispatch.

## Isolation and budgets

QuickJS has a per-invocation memory limit, stack limit, interrupt deadline, cancellation signal, bounded output and logs, bounded state, and tool-call budget. Host calls cross a JSON boundary. A host must still enforce path, network, credential, and sandbox policy in its binding implementation.

Code, payload, generated declaration, tool input, tool output, discovery, and formatted result
budgets are enforced before dispatch. Cancellation does not await non-cooperative host promises;
late completions are prevented from touching disposed QuickJS handles. Role policies are host
constraints and invocation policies can only narrow them.

`host-agentos` intentionally accepts narrow virtual-workspace and disposable-sandbox callbacks. It does not provide arbitrary host file or process APIs. The background runtime registers only the model-facing `code_mode` tool and no interactive commands or widgets.

AgentOS Pi profiles must be provisioned separately in a trusted environment. `PI_ACP_PI_COMMAND` and `PI_CODING_AGENT_DIR` are generated by the package helper; do not mount an operator's complete Pi directory or pass long-lived credentials to a sandbox.
